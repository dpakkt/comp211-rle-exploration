# Resources

These are some of the resources I used while working through this project and learning more about RLE and its implementation in C.

- **COMP 211 Course Materials** – Helped me connect the project to topics we covered in class, especially pointers, arrays, memory allocation, and working with bytes.
- **C Standard Library Documentation** – Used to better understand functions like `malloc()`, `free()`, and `memcmp()`.
- **C Documentation on Integer Types** – Helped me understand `size_t`, unsigned integers, and why integer limits matter when allocating memory.
- **AddressSanitizer Documentation** – Helped me understand how tools can detect memory errors such as buffer overflows and use-after-free errors.
- **Run-Length Encoding (RLE)** – Used to understand the basic compression method and how repeated values can be represented as count-value pairs.
